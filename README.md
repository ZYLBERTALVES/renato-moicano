# Renato "Money" Moicano

Página esportiva dedicada ao lutador Renato “Money” Moicano, desenvolvida com HTML e CSS.

O projeto apresenta momentos marcantes da carreira do lutador em um layout editorial inspirado em páginas esportivas e de MMA.

![Preview do projeto](imagem/FOTOPRINCIPALHERO.PNG)

## Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts
- GitHub Pages

## O que pratiquei neste projeto

- Estrutura semântica com HTML
- Hero section com imagem de fundo
- Uso de gradientes
- Tipografia responsiva
- Layout editorial
- Responsividade para celular e desktop
- Organização de imagens
- Publicação com GitHub Pages
